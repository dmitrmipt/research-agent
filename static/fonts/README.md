# Шрифты интерфейса

Шрифты поставляются вместе с приложением и загружаются с локального сервера. Для оформления не требуется обращение к внешним сервисам шрифтов.

- **Inter 4.1**, переменный шрифт для интерфейса: [официальный файл](https://github.com/rsms/inter/blob/v4.1/docs/font-files/InterVariable.woff2), [лицензия SIL Open Font License 1.1](Inter-OFL.txt).
- **PT Serif**, обычное и полужирное начертания для заголовков: [исходные файлы Google Fonts](https://github.com/google/fonts/tree/main/ofl/ptserif), [лицензия SIL Open Font License 1.1](PTSerif-OFL.txt).

Файлы получены 12 ноября 2026 года и включены без изменений. К шрифтам применяются их собственные лицензии, сохранённые в этой папке.
