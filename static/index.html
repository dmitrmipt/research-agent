Новый разбор

Статья, ваши вопросы и первый взгляд на результаты.

Материал для разбора

Можно указать ID или ссылку. При обработке будет скачана последняя опубликованная версия.

До 15 МБ. Текст извлекается из текстового слоя PDF.

Фокус внимания

Для отдельных ответов пишите по одному вопросу со знаком «?» на строку или пронумеруйте вопросы. Остальной текст задаёт акценты обзора.

Короткая статья передаётся целиком. Для длинной выбираются фрагменты до 2000 символов с перекрытием до 200: общий охват и материал по вашим вопросам. Усилие модели выбирается отдельно ниже.

Начальные значения берутся из настроек. Выбор здесь применяется только к этой статье.

Фрагменты текста и ваши вопросы передаются в OpenAI, поисковые термины — в arXiv и Crossref. Вызовы модели могут расходовать средства API.

Модель и ограничения

Усилие управляет рассуждением модели. Высокие значения могут увеличить время и расход токенов. Охват текста задаётся отдельно для статьи.

Другой идентификатор модели

Для неизвестных моделей цена и совместимость не подтверждены; усилие — по умолчанию.

При первичном разборе первый вызов готовит обзор, второй сравнивает публикации. При продолжении лимит относится к недостающим этапам нового задания.

Время отсчитывается с начала обработки. Остановка задания прекращает последующие запросы. Уже отправленный запрос может расходовать средства API.
